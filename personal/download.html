第一次安装

从安装 WorkBuddy 到看到第一份日报。图中界面为步骤示意，实际按钮以你的客户端为准。

已装并登录 WorkBuddy？跳到第 3 步 ↓

  1. 下载 WorkBuddy

    在要安装小咪的 Windows 电脑上打开腾讯的下载页，选 WorkBuddy 下的 Windows (x64)，等下载完成。

    腾讯官方 WorkBuddy 下载 ↗

  2. 安装并登录 WorkBuddy

    在 Windows 的「下载」文件夹中，双击刚下载的安装程序。按向导完成安装，打开 WorkBuddy，按页面提示登录。

    查看腾讯云 Windows 安装图文 ↗

  3. 发一句话，让 WorkBuddy 安装小咪

    复制本页的安装指令，回到 WorkBuddy 新建对话，粘贴并发送。跟着它的提示继续。

    回到安装指令 ↑

  4. 确认关注群，打开第一份日报

    由你本人在 WorkBuddy 中完成钉钉授权，选择你要关注的群，并确认是否允许小咪读取本机的日报和提醒文件。等第一份日报生成后，双击桌面上的小咪，或在系统托盘右键小咪并选「打开消息汇总」。

    看看日报示例 ↗

安装后有疑问？

装好了，却还没有日报

先确认钉钉群已授权、小咪可以读取本机日报。等 WorkBuddy 生成第一份日报后，再打开小咪的消息汇总。

电脑上已经有小咪

使用同一条安装指令，WorkBuddy 会按说明识别已有安装并保留资料。已装更新版本的用户可以继续使用现有版本。
